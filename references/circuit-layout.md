# 中学教材电路布局规则 v1

本规则用于普通初高中直流电路的教学展示。电路图表达连接关系，不按实物照片的导线长度计算。应用负责布局和导线路径；Skill负责识别题意、调用实际能力并查看最终画面。规则不会赋予旧版应用新算法。

## 不可改变的题意

- 先从题文、题图建立端子连接关系，分清相交和接通。布局只改变位置和展示朝向，保留器材ID、连接端子、参数、开关状态和电表极性。
- 电流表串入所测支路，电压表跨接指定的两个电气节点。电压表不作为主回路的串联负载。题目故意错接、短接或研究故障时保留错误接法，报告求解限制，不能悄悄改成正确接法。
- 开关断开不删除导线；布局按可能的支路结构排列，物理求解继续使用真实开合状态。复杂混联、桥式、多个电源不能靠挪动器材伪装成串并联。
- 原图未要求保留具体位置时允许等效重排；题图中的物理参数不因排版改变。非理想电源/电表参数、量程或额定限制必须以目录支持为准。当前没有量程/额定电流原生字段时，保留题设并依据真实读数外部核验，说明应用不会自动保护。

## 应用采用的结构规则

1. 单电源串联沿电源正端到负端的顺序排列，在矩形主回路上下两排分配器材；左侧电源回线共用竖直边界，避免台阶。器材不足时允许一排负载和空白回线。
2. 并联支路共享相同的两个电气节点，水平平行排列、保持留白。可归约的串并联组合递归分组，不依靠“电阻数量”猜结构。
3. 电压表优先位于被测器件附近的独立支路，避免压在主回路上；跨多个器件的测量仍连接原指定节点，截图检查路径。多个电表分开留位。
4. 导线沿横平竖直路径，端子方向和两端引出段共同计入转弯代价。先避让器材与不同节点导线，再减少无必要转弯；不能为了绝对最短路径遮挡器材。
5. 同节点的T形分支显示实心连接点；不同节点交叉显示跨线桥，交叉不修改电气连接。导线共线重叠可能造成误读，必须报告。
6. 未识别为单电源可归约串并联结构的网络采用通用布局并返回提示；不声称支持任意复杂网络的最优或无交叉排版。

## 调用与保留手动布局

- 新建纯电路：通常在 `scene.validate` / `scene.apply` 规格中使用 `layout:"circuit"`，`auto` 也会整理纯电路的新场景。不要习惯性使用 `preserve` 绕过布局。
- 用户指定具体摆放、原题研究接错情况、混合领域或已有手工场景：可用 `preserve`，先说明保留的原因，再按实际情况改善局部导线路径。
- 检查 `capabilities.textbookCircuitLayout` 和 `circuitGeometryInspection`。支持时 `circuit.inspect {}` 只读返回 issues 和 metrics；需要重新整理时先确认编辑状态，再调用 `circuit.layout {}`。运行/暂停中的结构不得直接修改；重置会清除本次运行进度，应按用户任务需要执行。
- `circuit.layout` 可撤销，返回结构类别、通用布局提示和几何检查。界面的「整理电路」使用同一规则。此操作不修改电阻、电源电压或接线。
- 旧版本没有能力声明时，不调用不存在的命令。使用其实际支持的 `layout:"circuit"` 或手动精确坐标，并截图核对；必要时明确说明需要新版才能稳定自动排版。

## 完成门禁

- `circuit.inspect.ok` 仅涵盖导线和器材几何，不证明读数、题意或标签排版正确。检查穿器材、器材重叠、不同节点导线重合和可直接消除的折弯；交叉数量只是指标，允许的跨线桥不等同于错误。
- 实际查看截图：简单回路无多余台阶；并联支路易区分；电压表确实跨接所测部分；连接点、极性、电流箭头和关键读数清楚；卡片不挡器材。必要时只显示选中及固定的关键量表。
- 整理后重新读取真实电压、电流和功率，与整理前及题目公式核对；不能只比较显示文字。
- 有无法消除的复杂交叉、原生参数缺失或超量程能力限制时如实说明。仍有明显可修复的布局问题时继续调整，不能以“计算正确”结束。
